## Assignment 1 — PixelHub

A responsive game-store single-page application built with Vue 3, Vite and
Bootstrap 5. Features a hero with working search, trending / most-played
product rows, a filterable catalogue of 18 games with categories and sample
RMB prices, top categories, an about section and a footer.

### Run it

```bash
cd assignment_1
npm install
npm run dev
```

Then open the printed local URL (default `http://localhost:5173`).

### Build for production

```bash
npm run build
npm run preview
```
